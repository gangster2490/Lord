# ROB AI Keyboard

Системная Android-клавиатура (Kotlin, `InputMethodService`, Jetpack Compose) с офлайн-подсказками,
Auto Emoji, историей буфера обмена, голосовым вводом, переводчиком и AI Writing (ChatGPT / Claude).

Цель — Samsung Galaxy S24 Ultra и Galaxy Tab S8+, работает на любом Android 8.0+ (ARM).

## Установка на телефон

1. Скопируйте `app-debug.apk` на телефон и откройте его. Разрешите установку из этого источника
   (Samsung: *Настройки → Приложения → Специальный доступ → Установка неизвестных приложений*).
2. Откройте приложение **ROB AI Keyboard** → «Открыть настройки клавиатур» → включите ROB AI Keyboard.
   Android покажет стандартное предупреждение, что клавиатура может видеть вводимый текст — так
   выглядит предупреждение для любой сторонней клавиатуры.
3. «Выбрать клавиатуру» → ROB AI Keyboard.
4. (Необязательно) *Настройки → Общее управление → Язык и ввод → Проверка правописания* → ROB AI Keyboard.
5. (Необязательно) В разделе «AI» вставьте свой API-ключ OpenAI и/или Anthropic для AI Writing.
6. (Необязательно) В разделе «Переводчик» скачайте офлайн-модели RU/DE/EN (~30 МБ каждая).

## Сборка

Нужны JDK 17+ и Android SDK 35.

```bash
cd rob-keyboard
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew testDebugUnitTest   # юнит-тесты
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
```

Словари: русский ≈150 000 слов, немецкий ≈100 000, английский 40 000 (частотные списки FrequencyWords с отсечкой редких опечаток).
Данные словарей и Emoji пересоздаются скриптом `tools/build_data.py` (источники описаны в его заголовке).

## Управление

| Действие | Как |
|---|---|
| Смена языка | свайп по пробелу (или выбрать «Курсор» в настройках) |
| Перемещение курсора | долгое нажатие на пробел и движение влево/вправо |
| Цифры и доп. символы (ё, ä, ß, é…) | долгое нажатие на клавишу |
| Голосовой ввод | 🎤 на панели или долгое нажатие на «,» |
| Удаление слов | свайп влево от ⌫; долгое нажатие ⌫ — сначала буквы, потом слова |
| Удалить весь текст | держать ⌫ → «✕ Удалить всё» («Отменить» вернёт текст) |
| Caps Lock | двойное или долгое нажатие ⇧ |
| Исправить весь текст одной кнопкой | ✎ справа в строке подсказок («Отменить» — вернуть как было) |
| Полная панель AI Writing | долгое нажатие на ✎ или кнопка на панели |
| Отмена автокоррекции / Auto Emoji | ⌫ сразу после замены |
| Двойной пробел | точка и пробел |
| Дизайн и цвета | Настройки → «Дизайн»: 11 тем (ROB Cyan, Modern Dark, Neon Purple, Nature Green, Sunset Orange, Cute Pink, Light Clean, Red & Black, Ice Blue, Minimal, Premium Gold) |

## Архитектура

```
app/src/main/java/com/rob/aikeyboard/
  ime/        RobKeyboardService (вся логика ввода), состояние, lifecycle для Compose
  keyboard/   раскладки, KeyboardView (рисование клавиш на Canvas, жесты), тема
  text/       словари, автокоррекция (взвешенное расстояние Дамерау–Левенштейна с учётом соседних клавиш),
              подсказки, биграммы, определение языка, выученные слова
  emoji/      каталог Unicode Emoji + поиск, история, Auto Emoji (правила, локально)
  clipboard/  правила истории буфера (10 + закреплённые)
  ai/         промпты AI Writing, клиент OpenAI / Anthropic
  translate/  ML Kit (на устройстве) + облачный вариант через AI
  voice/      системный SpeechRecognizer
  launch/     открытие приложений ChatGPT / Claude / Gemini
  security/   AES-GCM с ключом в Android Keystore
  spell/      системный сервис проверки орфографии
  ui/         панели клавиатуры (Compose), экран настроек, Photo Picker, запрос разрешений
```

## Конфиденциальность

- Обычный набор текста никуда не отправляется: подсказки, автокоррекция, Auto Emoji и офлайн-перевод
  работают на устройстве.
- В облако (OpenAI / Anthropic) текст уходит только после нажатия «Отправить» в AI Writing или
  при облачном переводе; перед отправкой текст показывается.
- API-ключи не входят в APK: пользователь вводит свой, он хранится зашифрованным (Android Keystore).
- Выученные слова, история буфера и картинки хранятся в зашифрованных файлах приложения;
  резервное копирование данных приложения отключено.
- В полях паролей: нет подсказок, обучения, AI, Auto Emoji и записи буфера. В полях с флагом
  «без персонального обучения» (инкогнито) слова не запоминаются.
- Нет рекламы, аналитики и журналов нажатий. Разрешения: интернет (только AI и загрузка моделей),
  микрофон (запрашивается при первом нажатии 🎤), вибрация.
