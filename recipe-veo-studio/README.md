# Recipe VEO Studio

Одно поле: название блюда. Агент на русском пишет полный рецепт, 8-секундный кулинарный промпт Veo 3.1, негативный промпт, озвучку, название для TikTok и ровно 5 хештегов. Промпт копируется в Gemini.

Ролик снимает Veo, не это приложение.
