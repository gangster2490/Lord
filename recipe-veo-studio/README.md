# Recipe VEO Studio

Личная студия **8-секундных рецептов для Veo 3.1**. Загружаете фото товара — приложение собирает production-промпт из 12 секций. Ролик снимает Veo, не это приложение.

Первый запуск сразу открывает живую студию: три готовых рецепта и черновик с демо-фото. Сборка идёт на телефоне, API-ключ не нужен.

| | |
|---|---|
| applicationId | `de.spardirekt.recipeveo` |
| minSdk / targetSdk | 26 / 35 |
| version | 1.0.0 |
| Данные | `filesDir/studio.json` |

## Экраны

1. **Студия** — готовые рецепты, черновик, статистика
2. **Собрать** — фото товара, пожелание, голос, стиль, TikTok Shop
3. **Рецепты** — библиотека готовых промптов
4. **Стили** — 8-секундные shot-рецепты, которые можно применить к проекту
5. **Промпт** — копирование пакета целиком
