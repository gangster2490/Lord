# Recipe VEO Studio

Личная студия рецептов для **8-секундного VEO 3.1**. Приложение не снимает ролик — собирает production-промпт (12 секций), voiceover, title и hashtags, чтобы вставить их в Veo / Gemini.

Первый запуск сразу открывает библиотеку из четырёх готовых рецептов. Сеть и API-ключ не нужны: компилятор работает на устройстве.

| | |
|---|---|
| applicationId | `de.spardirekt.recipeveo` |
| minSdk / targetSdk | 26 / 35 |
| Данные | `filesDir/studio.json` |

## Экраны

1. **Студия** — библиотека рецептов, поиск, фильтр по категории
2. **Рецепт** — объект, стиль, product lock, четыре блока по 2 с, голос
3. **Промпт** — VEO-текст, копирование пакета, шаринг
4. **Ещё** — тема, голос по умолчанию, примеры, очистка

Категории: еда, напиток, продукт, бьюти, лайфстайл.  
Стили: студия, макро, satisfying, lifestyle, кино, улица.
