# Recipe VEO Studio

Личная студия **8-секундных VEO 3.1** промптов. Загружаете фото товара — приложение собирает production-рецепт (12 секций: FORMAT … HASHTAGS), voiceover, title и 5 hashtags. Ролик снимает Veo, не это приложение.

Первый запуск сразу показывает демо-проект Velvet Gold в истории. На вкладке «Создать» можно добавить свои фото или демо-кадр и собрать промпт на устройстве — API-ключ не нужен.

| | |
|---|---|
| applicationId | `de.spardirekt.recipeveo` |
| minSdk / targetSdk | 26 / 35 |
| version | 1.1.0 |
| Данные | `filesDir/studio.json` + `filesDir/photos/` |

## Экраны

1. **Создать** — фото товара (до 15), пожелание, голос DE/RU/off, creative mode, TikTok Shop
2. **История** — готовые промпты и черновики с фото
3. **Промпт** — копирование VEO-текста, voiceover, title, hashtags, пакет целиком
4. **Ещё** — тема, голос новых проектов, демо, очистка
