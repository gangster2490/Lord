# Recipe VEO Studio

Одно поле: название блюда. Агент через OpenAI пишет на русском полный рецепт, 8-секундный промпт Veo 3.1, негативный промпт, озвучку, название для TikTok и ровно 5 хештегов. Промпт копируется в Gemini.

Ролик снимает Veo, не это приложение.
