# Своё

Личное Android-приложение: задачи, привычки, дневник и простой учёт денег. Без аккаунта, без сети, без аналитики. Всё лежит в одном JSON-файле на телефоне.

| | |
|---|---|
| applicationId | `de.spardirekt.svoe` |
| minSdk / targetSdk | 26 / 35 |
| UI | Kotlin, Jetpack Compose, Material 3 |
| Данные | `filesDir/life.json` |

## Собрать

Нужны JDK 17+ и Android SDK 35.

```bash
cd svoe
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew :domain:test assembleDebug
```

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`

Установка на устройство:

```bash
./gradlew installDebug
```

## Экраны

1. **Онбординг** — имя и валюта (EUR / RUB / USD)
2. **Сегодня** — приветствие, дела на день, привычки, настроение, черновик дневника
3. **Задачи** — приоритет, срок, поиск, готовые можно скрыть
4. **Привычки** — неделя с понедельника, серии дней, архив
5. **Дневник** — настроение 1–5 и текст за сегодня, история
6. **Деньги** — расход/доход, категории, итог месяца
7. **Настройки** — тема, валюта, примеры данных, полная очистка

Тема: тёплая бумага и терракота, светлая / тёмная / как в системе.
