# Своё

Личное Android-приложение: задачи, привычки, дневник и простой учёт денег. Без аккаунта, без сети, без аналитики. Первый запуск сразу показывает живой день — данные только на телефоне.

| | |
|---|---|
| applicationId | `de.spardirekt.svoe` |
| minSdk / targetSdk | 26 / 35 |
| UI | Kotlin, Jetpack Compose, Material 3 |
| Данные | `filesDir/life.json` |

## Экраны

1. **Сегодня** — приветствие, дела, привычки, настроение, дневник
2. **Задачи** — приоритет, срок, поиск
3. **Привычки** — неделя с понедельника, серии дней, архив
4. **Дневник** — настроение 1–5 и текст за день
5. **Деньги** — расход/доход, категории, итог месяца
6. **Настройки** — имя, тема, валюта, примеры, очистка

Тема: тёплая бумага и терракота, светлая / тёмная / как в системе. Debug APK собирает CI и кладётся в артефакты workflow `svoe`.
