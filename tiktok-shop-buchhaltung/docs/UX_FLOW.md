# UX Flow

## Start / Dashboard
Buttons:
- `Einnahme erfassen`
- `Ausgabe erfassen`
- `Belege prüfen`
- `Export`

Dashboard-Karten:
- Angezeigt
- Eingefroren
- Verfügbar
- Ausgezahlt
- Ausgaben
- Ergebnis

## Einnahme erfassen
1. Quelle wählen: Kamera / Galerie / manuell.
2. OCR läuft.
3. Vorschau:
   - Datum
   - TikTok Shop
   - Provision
   - Betrag
   - Status
4. Bildvorschau daneben/oben.
5. Buttons: `Speichern` / `Korrigieren` / `Abbrechen`.

## Ausgabe erfassen
1. Kamera / Galerie.
2. OCR.
3. Vorschau:
   - Datum
   - Händler
   - Betrag
   - Kategorie
   - Geschäftsanteil
4. `Speichern`.

## Belege prüfen
Liste aller Einträge mit Warnungen:
- OCR unsicher
- kein Beleg
- Geschäftsanteil fehlt
- möglicher Doppelbeleg

## Detailansicht
- alle Felder editierbar
- Originalbild öffnen
- Statushistorie
- löschen nur mit Bestätigung

## Export
- Jahr/Zeitraum
- CSV
- ZIP inkl. Belege
- optional PDF/XLSX später
