# Будильник (Android)

Нативный будильник на Kotlin + Jetpack Compose. Готовый APK: [`release/Budilnik.apk`](release/Budilnik.apk) (Android 8.0+).

## Возможности

- Несколько будильников: время, название, повтор по дням недели (будни / выходные / каждый день / однократно)
- Срабатывает точно и в режиме Doze (`AlarmManager.setAlarmClock`), значок будильника в статус-баре
- Полноэкранный экран звонка поверх блокировки: «Отложить» / «Выключить» (и кнопки в уведомлении)
- Выбор мелодии из системных, вибрация, плавное нарастание громкости
- Настройки: длительность «отложить» (5–30 мин), сколько звонить до автоматической остановки
- Восстановление будильников после перезагрузки, обновления приложения, смены времени / часового пояса
- Часы на главном экране и отсчёт «Следующий: 07:00 — через 8 ч 15 мин»

## Установка

1. Скачайте `release/Budilnik.apk` на телефон и откройте его.
2. Разрешите установку из неизвестных источников, если Android спросит.
3. При первом запуске разрешите уведомления. Если на главном экране видна жёлтая плашка — нажмите «Разрешить»
   (точные будильники / полноэкранные уведомления на Android 12+ / 14+).

На некоторых прошивках (Xiaomi, Huawei, Samsung) стоит дополнительно отключить для приложения оптимизацию батареи.

## Сборка

```bash
cd alarm-android
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew testReleaseUnitTest assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`. Release подписан debug-ключом сборщика, чтобы ставиться напрямую;
APK, собранный на другой машине, обновит установленный только после удаления старого.
