# Checklist for your Galaxy S24 Ultra (≈10 minutes)

1. Install `ROB-Neon-1.0.0-debug.apk`; open it. Check RU/DE (change phone language), tabs, search "telegram".
2. **Icons tab:** note blue dots (matched) vs red dots (installed, activity differs). Photograph any red dot's detail dialog.
3. Install Good Lock + Theme Park (Galaxy Store). Open Theme Park from the app (Home → "Open Theme Park").
4. In Theme Park open the Icons section: **is "ROB Neon" listed?** Apply it. Record the One UI and Theme Park versions.
5. On the home screen tap 5 icons (Phone, Camera, Chrome, WhatsApp, Settings): each must open the original app.
6. **Wallpapers tab:** use "system crop" for Home, then for Lock; if the system dialog does not appear try "open in another app". Confirm the destination dialog and the crop.
7. Add Samsung Clock/Weather widgets per the in-app steps.
8. Update test: tick two steps in "Steps", install the same APK again with `adb install -r` (or a higher versionCode build signed with the same key); ticks must remain.
9. Report back: Theme Park listed it (yes/no), red dots, wallpaper flow behaviour.
